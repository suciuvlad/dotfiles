# Contributing

Marketing Brain is proprietary source-available software for paid license
holders and active AI Marketing Hub Pro members.

External pull requests are not accepted unless Daniel Agrici has agreed to the
work in writing before it is submitted. This keeps ownership, customer access,
and commercial licensing unambiguous.

Authorized users can still help by opening focused issues:

- reproducible bugs
- documentation errors
- security concerns, reported through [SECURITY.md](SECURITY.md)
- compatibility notes for supported Python or Obsidian versions

Do not include DataForSEO credentials, client secrets, private analytics
exports, or confidential client material in issues or pull requests.

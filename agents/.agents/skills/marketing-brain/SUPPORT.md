# Support

Support is available for paid Marketing Brain license holders and active AI
Marketing Hub Pro members.

For normal product issues, open a GitHub issue with:

- the Marketing Brain version
- operating system and Python version
- the command you ran
- the smallest safe reproduction
- sanitized error output

For vulnerabilities, follow [SECURITY.md](SECURITY.md) and use a private
security advisory. Never post API credentials, client secrets, private client
exports, or raw DataForSEO response bodies in public issues.
